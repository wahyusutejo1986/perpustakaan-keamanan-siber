# 🧭 Panduan Menggunakan Perpustakaan Keamanan Siber

Selamat datang di **Perpustakaan Keamanan Siber Indonesia**! Repositori ini dirancang seperti perpustakaan digital terbuka yang dapat diakses oleh siapa saja dengan latar belakang yang beragam.

Agar Anda tidak bingung di mana harus memulai, temukan profil Anda di bawah ini dan ikuti rekomendasinya.

*Tujuan: Ingin terhindar dari penipuan online, mengamankan data pribadi, dan memahami cara kerja dunia digital.*
- [x] Baca [Panduan Cyber Hygiene & Privasi](../01-fondasi-teknis-dan-literasi/cyber-hygiene-masyarakat.md) — Pelajari manajemen sandi, 2FA, dan cara mengenali phishing (file `.apk` palsu, pesan penipuan).

## 📌 Fitur Unggulan Tiap Folder Domain
Setiap folder domain (Offensive, Defensive, Forensik, Cloud, GRC) memiliki struktur standar:
1. **`roadmap-...md`**: Tahapan penguasaan dari Level 1 sampai Level 4.
2. **`katalog-tools-...md`**: Kurasi tools open-source unggulan beserta fungsinya.
3. **`metodologi / framework-...md`**: Standar industri global (NIST, MITRE, OWASP, ISO) dan implementasi di Indonesia.
4. **`latihan / best-practices-...md`**: Tempat latihan lab, konfigurasi hardening, atau playbook praktik.

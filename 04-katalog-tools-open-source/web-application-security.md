# 🌐 Katalog Tools Open Source: Keamanan Aplikasi Web

Daftar perangkat lunak sumber terbuka (open source) yang digunakan untuk analisis dan pengujian keamanan aplikasi web.

---

### [OWASP ZAP (ZAPROXY)](https://www.zaproxy.org/)
- **Kategori**: Web Interception Proxy & Scanner
- **Lisensi**: Apache License 2.0
- **Tingkat Kesulitan**: Pemula - Menengah
- **Deskripsi**: Alternatif open-source terbaik untuk Burp Suite. Digunakan untuk mencegat request/response HTTP, pemindaian kerentanan otomatis, dan spidering halaman web.
- **Tutorial**: [Dokumentasi Resmi ZAP](https://www.zaproxy.org/docs/)

### [Nuclei](https://github.com/projectdiscovery/nuclei)
- **Kategori**: Vulnerability Scanner Berbasis Template
- **Lisensi**: MIT License
- **Tingkat Kesulitan**: Menengah
- **Deskripsi**: Scanner berbasis bahasa Go yang sangat cepat dan dapat disesuaikan menggunakan template YAML untuk mendeteksi ribuan CVE dan miskonfigurasi web.
- **Tutorial**: [Nuclei Documentation by ProjectDiscovery](https://docs.projectdiscovery.io/tools/nuclei)

### [Sqlmap](https://sqlmap.org/)
- **Kategori**: Automatic SQL Injection & Database Takeover
- **Lisensi**: GPL v2.0
- **Tingkat Kesulitan**: Menengah
- **Deskripsi**: Tool otomatisasi open-source untuk mendeteksi dan mengeksploitasi celah SQL Injection serta mengambil alih basis data.
- **Peringatan**: Hanya gunakan pada target resmi atau lab pribadi!

### [ffuf (Fast Web Fuzzer)](https://github.com/ffuf/ffuf)
- **Kategori**: Web Directory & Parameter Fuzzing
- **Lisensi**: MIT License
- **Tingkat Kesulitan**: Pemula - Menengah
- **Deskripsi**: Alat fuzzing berbasis Go yang sangat cepat untuk menemukan file tersembunyi, endpoint API yang tidak terdokumentasi, dan direktori web.

### [Wappalyzer (CLI / Extension)](https://www.wappalyzer.com/)
- **Kategori**: Technology Profiler
- **Tingkat Kesulitan**: Pemula
- **Deskripsi**: Mengidentifikasi teknologi, framework (Laravel, Django, React), web server (Nginx, Apache), dan CMS yang digunakan pada situs web target.

# 🛠️ Katalog Tools Open Source: Forensik Digital & Analisis Malware

Daftar perangkat lunak open source untuk investigasi kejahatan siber, ekstraksi artefak, analisis memori, dan dekompilasi malware.

---

## 💾 1. Disk Forensics & Triage Artefak

### [Autopsy](https://www.autopsy.com/)
- **Kategori**: Digital Forensics Platform
- **Lisensi**: Apache 2.0
- **Fungsi**: Antarmuka grafis (GUI) berbasis The Sleuth Kit (TSK) untuk menganalisis hard disk, kartu memori, dan smartphone guna menemukan file terhapus, riwayat web, dan metadata dokumen.

### [KAPE (Kroll Artifact Parser and Extractor)](https://www.kroll.com/en/services/cyber-risk/incident-response-litigation-support/kroll-artifact-parser-extractor-kape)
- **Kategori**: Rapid Forensic Triage
- **Fungsi**: Tool triage sangat cepat untuk mengekstrak dan mem-parsing artefak forensik Windows yang paling penting dalam hitungan menit.

---

## 🧠 2. Analisis Memori RAM

### [Volatility 3](https://github.com/volatilityfoundation/volatility3)
- **Kategori**: Memory Forensics Framework
- **Lisensi**: VSL v1.0
- **Fungsi**: Standar industri global untuk menganalisis *memory dump* RAM (Windows, Linux, macOS). Dapat mendeteksi injeksi DLL, memulihkan sesi baris perintah (cmd/bash), dan mengekstrak kunci enkripsi.

---

## 🔬 3. Analisis Malware & Reverse Engineering

### [Ghidra](https://ghidra-sre.org/)
- **Kategori**: Software Reverse Engineering (SRE) Suite
- **Lisensi**: Apache 2.0
- **Fungsi**: Framework dekompilasi dan disassembly biner canggih yang dirilis secara open-source oleh NSA. Mendukung berbagai arsitektur CPU (x86, x64, ARM, MIPS).

### [CyberChef](https://gchq.github.io/CyberChef/)
- **Kategori**: The Cyber Swiss Army Knife
- **Lisensi**: Apache 2.0
- **Fungsi**: Aplikasi web open-source buatan GCHQ untuk mendekode string terobfuskasi, dekompresi data, konversi Base64/Hex, analisis timestamp, dan kalkulasi hash.

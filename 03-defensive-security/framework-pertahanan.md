# 🛡️ Framework & Arsitektur Pertahanan Siber

Pertahanan siber modern tidak lagi mengandalkan feeling atau tebak-tebakan, melainkan menggunakan kerangka kerja (*framework*) berbasis data ancaman nyata.

---

## 🏛️ Framework Utama Industri

### 1. [MITRE ATT&CK®](https://attack.mitre.org/)
- **Definisi**: Basis pengetahuan (*knowledge base*) global mengenai taktik, teknik, dan prosedur (TTP) yang digunakan oleh penyerang siber berdasarkan observasi di dunia nyata.
- **Taktik Inti**:
  1. *Initial Access* (Cara musuh masuk)
  2. *Execution* (Cara kode dijalankan)
  3. *Persistence* (Cara musuh mempertahankan akses)
  4. *Privilege Escalation* (Cara meningkatkan wewenang)
  5. *Defense Evasion* (Cara menghindari deteksi)
  6. *Credential Access* (Pencurian sandi/token)
  7. *Discovery* (Mencari informasi di dalam sistem)
  8. *Lateral Movement* (Menyusup ke komputer lain di jaringan)
  9. *Collection* (Mengumpulkan data berharga)
  10. *Command and Control* (Komunikasi dengan server penyerang)
  11. *Exfiltration* (Mencuri data keluar jaringan)
  12. *Impact* (Merusak, mengenkripsi, atau menghentikan sistem)

### 2. [MITRE D3FEND™](https://d3fend.mitre.org/)
- **Definisi**: Matriks pengetahuan arsitektur teknis untuk teknik pertahanan siber (tandingan defensif langsung dari MITRE ATT&CK).

### 3. [NIST Cybersecurity Framework (CSF) 2.0](https://www.nist.gov/cyberframework)
- Terdiri atas 6 fungsi inti:
  - **GOVERN (Tata Kelola)**
  - **IDENTIFY (Identifikasi Aset & Risiko)**
  - **PROTECT (Perlindungan & Pengamanan)**
  - **DETECT (Pendeteksian Anomali)**
  - **RESPOND (Tindakan Terhadap Insiden)**
  - **RECOVER (Pemulihan Layanan)**

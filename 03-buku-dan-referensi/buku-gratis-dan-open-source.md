# 📚 Buku Digital Gratis & Materi Terbuka (Open Access)

Kumpulan buku, panduan, dan materi edukasi keamanan siber yang dapat diakses secara gratis dan legal.

---

## 📖 Buku Open Source / Gratis

### [OWASP Testing Guide (WSTG)](https://owasp.org/www-project-web-security-testing-guide/)
- **Penulis**: Komunitas OWASP
- **Bahasa**: Inggris (beberapa bagian telah diterjemahkan komunitas)
- **Akses**: Gratis / Terbuka
- **Tingkat**: Menengah - Lanjut
- **Deskripsi**: Panduan metodologi pengujian keamanan aplikasi web terlengkap yang diakui sebagai standar industri global.

### [PortSwigger Web Security Academy](https://portswigger.net/web-security)
- **Penulis**: Tim PortSwigger (Pembuat Burp Suite)
- **Bahasa**: Inggris
- **Akses**: 100% Gratis (Artikel teori + Interactive Labs)
- **Tingkat**: Pemula - Mahir
- **Deskripsi**: Sumber belajar web security terbaik di dunia saat ini, mencakup SQLi, XSS, SSRF, Deserialization, hingga WebAssembly.

### [Red Team Field Manual (RTFM) & Blue Team Handbook (Materi Pengantar Terbuka)](https://github.com/mubix/post-exploitation)
- **Akses**: Referensi Terbuka (GitHub)
- **Tingkat**: Praktisi
- **Deskripsi**: Kumpulan cheatsheet perintah penting saat melakukan assessment sistem dan penanganan insiden.

### [Linux Basics for Hackers (Panduan Dasar Linux Terbuka)](https://nostarch.com/)
- **Tingkat**: Pemula
- **Deskripsi**: Konsep administrasi Linux, manajemen hak akses file, networking, dan bash scripting yang wajib dikuasai sebelum terjun ke keamanan siber.

## 🏛️ Standar & Framework Industri

- **[NIST Cybersecurity Framework (CSF) 2.0](https://www.nist.gov/cyberframework)**: Framework tata kelola keamanan siber internasional (Govern, Identify, Protect, Detect, Respond, Recover).
- **[MITRE ATT&CK Framework](https://attack.mitre.org/)**: Basis pengetahuan taktik dan teknik penyerang berdasarkan observasi di dunia nyata.
- **[CIS Critical Security Controls (CIS Controls)](https://www.cisecurity.org/controls)**: 18 kontrol keamanan terprioritas untuk mempertahankan organisasi dari serangan siber umum.
- **[BSSN Panduan Teknis](https://cloud.bssn.go.id/)**: Kumpulan pedoman penanganan insiden, tata kelola sandi, dan standar kepatuhan siber di Indonesia.
